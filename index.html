12-LED Heart Keychain

Bring your heart-shaped WS2812B keychain to life. Install the ElectroSurgeon firmware directly from your browser — no Arduino IDE needed for the flashing step.

⚡

Flash Your Keychain

Connect your ESP8266 D1 Mini to your computer with a data-capable USB cable, then start the installer.

Your browser does not support Web Serial. Open this page in desktop Chrome or Microsoft Edge over HTTPS.
Keep the keychain disconnected from external LED power while flashing. Select the USB serial port when your browser asks.

How to Install

  1. Use a desktop or laptop with the latest Chrome or Microsoft Edge.
  2. Open this page from its HTTPS GitHub Pages address.
  3. Connect the ESP8266 D1 Mini using a USB data cable.
  4. Click Install, choose the ESP8266 serial port and confirm.
  5. Wait for the process to finish before unplugging the board.
  6. After reboot, connect your phone to ElectroSurgeon_KEYChain (password: Electro123), then visit http://192.168.4.1.

Web flashing requires a secure HTTPS page and a browser with Web Serial support. iPhone/iPad browsers are not supported for this flashing workflow.

Firmware & Source

The installer reads the firmware binary listed in manifest.json. The source sketch is not itself a flashable binary. Compile the sketch for the ESP8266 D1 Mini and place the exported binary at the exact path shown in the manifest.
